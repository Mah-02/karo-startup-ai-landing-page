# Karo Startup AI Landing Page

This project is an AI-generated landing page created for the **Karo Startup Internship Assignment**.

## 🚀 Project Overview
The website allows startup founders to pitch their ideas to investors across India.

The landing page includes:
- Hero section introducing the platform
- Startup pitch explanation
- Call-to-action "Apply to Pitch"
- Clean modern layout for better user experience

## 🛠 AI Tool Used
Caffeine AI Website Builder

## 🎯 Why This Design?
The page focuses on simplicity and clear communication so founders can quickly understand how to pitch their startup to investors. The call-to-action button encourages founders to apply directly from the landing page.
